# Files

- `cd_plot_code.py` — Draws critical difference diagrams using Friedman-Nemenyi tests via the autorank library with customizable axis and line styling
- `eval_am_code.py` — Entry point that loads benchmark results from CSV and runs both CD diagram and normalized improvement evaluations
- `ni_plot_code.py` — Computes normalized improvement scores relative to a baseline method and renders them as a seaborn boxplot with stripplot overlay
